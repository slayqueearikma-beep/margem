# Dribex Email & Notification Policy

**Effective Date:** August 1, 2026  
**Last Updated:** August 5, 2026

---

## 1. Email Communications

### 1.1 From Addresses

| Address | Purpose |
|---------|---------|
| noreply@dribex.ma | Transactional emails (verification, password reset) |
| support@dribex.ma | Support correspondence |
| privacy@dribex.app | Privacy-related communications |

### 1.2 Email Types

| Email | Trigger | Frequency |
|-------|---------|-----------|
| Email verification | Account registration | Once per registration |
| Password reset | User request | Per request |
| Admin password reset | Admin action | Per action |
| Platform announcement | Admin broadcast | As needed |
| Marketing (future) | Opt-in only | Per consent |

### 1.3 Deep Links

Transactional emails may contain deep links:

- `margem://app/verify-email` — Email verification
- `margem://app/reset-password` — Password reset
- `https://dribex.ma/verify-email` — Web fallback
- `https://dribex.ma/reset-password` — Web fallback

---

## 2. In-App Notifications

### 2.1 Notification Types

| Kind | Example |
|------|---------|
| Premium activation | "Your Seller Pro subscription is active" |
| Verification update | "Your business verification was approved" |
| General alert | Platform announcements, feature updates |

### 2.2 Push Notifications

Dribex does not currently send push notifications (no FCM/APNs integration). In-app notifications are displayed when the app is open or accessed.

---

## 3. Managing Preferences

| Preference | How to Manage |
|------------|---------------|
| Marketing emails | Unsubscribe link or account settings |
| In-app notifications | Account settings (future) |
| All communications | Account deletion |

Transactional emails cannot be disabled while your account is active, as they are necessary for Platform operation.

---

## 4. Data in Communications

Emails and notifications may contain:

- Your display name
- Account-related information (verification links, reset tokens)
- Business name (for seller notifications)
- No sensitive data (passwords, full payment details)
