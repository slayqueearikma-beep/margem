# MarGem Accessibility Statement

**Effective Date:** August 1, 2026  
**Last Updated:** August 5, 2026

---

## 1. Our Commitment

MarGem is committed to making our Platform accessible to all users, including people with disabilities. We strive to conform to the **Web Content Accessibility Guidelines (WCAG) 2.1 Level AA** and applicable accessibility standards on mobile platforms.

---

## 2. Accessibility Features

### Mobile Applications (Android and iOS)

| Feature | Status |
|---------|--------|
| Screen reader support (TalkBack, VoiceOver) | Supported via Flutter semantics |
| Scalable text | Respects system text size settings |
| Color contrast | Material 3 design with sufficient contrast ratios |
| Touch targets | Minimum 48dp touch targets |
| Keyboard navigation | Supported on Web platform |
| Multi-language support | English, French, Arabic |

### Web Platform

| Feature | Status |
|---------|--------|
| Semantic HTML | Implemented |
| Keyboard navigation | In progress |
| Alt text for images | Required for uploaded content |
| Focus indicators | Implemented |
| Responsive design | Mobile-first responsive layout |

---

## 3. Known Limitations

We are aware of the following accessibility limitations and are working to address them:

- Map views may have limited screen reader support
- Some third-party embedded content (Google Maps) follows the provider's accessibility standards
- Arabic right-to-left (RTL) layout is supported but some UI elements may need refinement
- Video content in listings may lack captions (seller responsibility)

---

## 4. Ongoing Efforts

MarGem is committed to:

- Regular accessibility audits of new features
- Training development teams on accessibility best practices
- Incorporating accessibility requirements into our design system
- Responding to accessibility feedback promptly

---

## 5. Feedback and Assistance

If you encounter accessibility barriers on MarGem, please contact us:

- **Email:** accessibility@margem.ma
- **Response time:** 5 business days

Please include:

- Description of the accessibility issue
- Platform (Android, iOS, Web) and version
- Assistive technology used (if applicable)
- Steps to reproduce the issue

---

## 6. Alternative Access

If you are unable to access a feature due to accessibility barriers, contact support@margem.ma and we will provide alternative means of access where reasonably possible.
